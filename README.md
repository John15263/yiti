# 一题 · 跟着 Math Academy 学的中文陪练

一题是 [Math Academy](https://www.mathacademy.com) 的本地陪练工具，给用中文思考的学生用。它跟着你在 Math Academy 上正在看的那一步走：把英文翻成中文，给你这一步背后的**前置知识**（更基础的概念、方法、公式，每一项都可以进一步展开），并且随时可以**问一问**。卡住时也可以开语音问陪练。

它守一条线：**练习题交答案之前，不帮你解这道题。** Math Academy 根据你自己交的答案安排练习和复习；先被别人讲会了再交，它就会以为你已经掌握了。所以交答案之前，一题只翻译题目，最多用别的例子帮你补前置知识。交了之后（对错都行），再陪你把这道题弄懂。

![左边是一题，右边是 Math Academy：一题跟到同一道例题，显示中文翻译](docs/screenshot.webp)

> 这是个人学习用的非官方工具，和 Math Academy 没有关联。扩展只在你自己的浏览器里读你自己打开的页面，内容只发到你本机运行的一题。

## 两种用法

- **浏览器插件版（推荐）**：装一个 Edge / Chrome 插件，一题就在浏览器侧边栏里跟着 Math Academy 走。不用装 Node，不用命令行；所有模型都由插件直接调用，不经过任何服务器。见下面「插件版」。
- **本机服务版**：在电脑上跑一个 Node 服务，一题开在单独的标签页里，另装一个只负责读页面的小扩展。适合想改代码的人。

## 插件版

1. 拿到插件：从 [Releases](https://github.com/John15263/yiti/releases) 下载最新的 `yiti-extension-<版本>.zip` 并解压；或者自己构建（需要 Node 24）：`node edge/build.mjs`，生成 `dist/extension/` 文件夹。
2. Edge 打开 `edge://extensions`（Chrome 是 `chrome://extensions`），打开「开发人员模式」，点「加载解压缩的扩展」，选解压出来的文件夹（自己构建的话是 `dist/extension`；**不是**源代码里的 `edge` 文件夹，也不是仓库根目录的 `extension` 文件夹，那是本机服务版用的小扩展）。
3. 点工具栏上一题的图标，侧边栏打开，会弹出「设置」：填 API key，点「保存并测试」。**在中国大陆，一个阿里云百炼的 key 就够了**：文字选「阿里云百炼（千问）」，语音选「阿里云百炼」，区域选中国大陆，并填上**业务空间 ID**（插件里的语音走 WebRTC，必须用业务空间的专属地址；在百炼控制台右上角能看到）。
4. 打开或刷新 Math Academy 的一节课，侧边栏会跟到你正在看的那一步。还没有 Math Academy 账号的话，点「先看一个示例」，用一题自带的例题把各项功能试一遍。
5. 第一次按 ⌘] 开语音时，如果侧边栏没法直接要麦克风权限，一题会打开一个授权页，在那里允许一次就好。

插件的学习记录和 key 都存在浏览器的插件存储里，只发给你选的服务商。

## 需要什么

- Node.js 24 或更新（不需要 `npm install`，没有第三方依赖）
- Chrome（或其他 Chromium 浏览器）
- 模型的 API key，两部分可以分别选：
  - 文字部分（翻译、前置知识、问一问）：[Gemini](https://aistudio.google.com/apikey)、[DeepSeek](https://platform.deepseek.com)，或阿里云百炼的千问（和语音共用一个百炼 key）。
  - 语音陪练：Gemini Live，或阿里云百炼的 Qwen-Omni-Realtime（中国大陆可用，实测中文讲解很自然）。不配语音也能用，只是没有语音按钮。
  - 在中国大陆，**一个百炼 key 就能跑全套**（文字用千问、语音用 Qwen-Omni），不需要 Google 账号。

## 安装

```sh
git clone https://github.com/John15263/yiti.git
cd yiti
npm start               # 打开 http://127.0.0.1:4318
```

第一次打开会弹出「设置」：选文字和语音各用哪家服务，填上 API key，点「保存并测试」，马上就知道 key 能不能用。key 只存在本机的 `data/settings.json`，页面上只显示末尾四位。以后点右上角「设置」随时改。也可以照 `.env.example` 写 `.env`，网页里的设置优先。

装 Chrome 扩展（一次）：

1. Chrome 打开 `chrome://extensions`，右上角打开「开发者模式」。
2. 点「加载已解压的扩展程序」，选这个仓库里的 `extension` 文件夹。
3. 刷新 Math Academy 的页面。一题的页面会跟到你正在看的那一步。

扩展只在 mathacademy.com 上运行，只读**当前这一步**（页面里预先载入的后面几步不读），只发给本机的 `127.0.0.1:4318`。**复习页面**像练习题一样，读当前这一道题；测验、诊断、测评这些考核页面，只告诉一题"现在在测验"，不读题目内容。

用 AI Agent（Claude Code、Codex 等）安装的话，让它读 [AGENTS.md](AGENTS.md)。

## 怎么用

把一题和 Math Academy 并排放。界面只有一行顶栏（第几步、字号 A− A+、中英切换、设置）。字号是整个页面的：点 A− A+，或者按 ⌘＋ ⌘－（⌘0 还原），会记住；侧边栏本身不能用浏览器的缩放，所以一题自己做了这个。上面是这一步的内容和「前置知识」按钮。「问一问」（包括语音）平时收起，只在角落里留一小粒（问一问、语音）：点「问一问」（或按 ⌘/）展开，再点「收起」（或再按 ⌘/）收回去，记住你上次的选择。收起时，你没看着的时候来了新回复，问一问上会有一个小点；语音不用展开也能开，计时在那一小粒里，结束、出错会在旁边提示几秒。展开后停在下面，往下翻内容时它不动，所以可以一边看前置知识一边提问；页面够宽时（在标签页里打开，或把侧边栏拉宽）是右边一栏。上沿可以拖动调大小，大小也会记住。在页面里划线提问，会把它自己打开。讲解、例题、练习题都是这一套。

**中文显示**：默认把每一步翻成中文（题目、选项、讲解、例题，连公式里的文字也翻），公式本身原样保留。顶栏的「EN」切回英文原文，「中」切回来。每一步只翻一次；某一段翻得不完整时，那一段显示原文。

**公式**：讲解和例题里 Math Academy 事先排好版的公式，矩阵、方程组、分式这类部分在它的源码里已经是排好的样子（纯文字会变成 `A=[2613]` 这种挤在一起的数字），一题从里面附带的数学标记把它们还原成 TeX；MathJax 读不了的公式不再显示它的报错，改用 TeX 自己画。矩阵、分式等按 Math Academy 页面给的数学标记画；如果标记里丢了表格（矩阵被压成一行数字，读起来像别的数），就改用 TeX 自己重画，`\underbrace` 这类也支持。仍然不对时，打开「设置」，点「复制这一步的公式」，粘贴给开发者：里面只有这一步的公式（TeX、页面给的标记、这里画出来的），没有文字，也不会发到任何地方。

**公式**：Math Academy 原文里的公式照原样显示。模型写的前置知识和回答里，有结构的数学（矩阵、分式、根号等）也会渲染成公式，矩阵的括号会撑到整个矩阵的高度；模型没写对的写法，就显示它原来的 LaTeX。你自己提问时，纯文本就行，矩阵写成 `[[1,2],[3,4]]` 之类都行。

**讲解和例题**：整段原文翻成中文，一次看完，不分块、不遮住、不用默写。看不懂的地方，点「前置知识」看它背后的基础，或者直接问一问。

**练习题**：先在 Math Academy 做完、交答案，答错也没关系。它守一条线：交答案之前，一题不帮你解这道题，只帮你补前置知识。交了之后（对错都行），可以看官方讲解，也可以什么都问，包括这道题怎么做。

**知识点讲义页**：Math Academy 的 Topics 页面（`/topics/<名称>-<编号>`）是一个知识点的完整讲义：讲解和例题都在一页上，没有练习题。一题跟着屏幕上正在看的那一段走，和课程里的讲解、例题一样：翻译、前置知识、定位、「学这个有什么用」、问一问、更简单的解释都能用。以后复习这个知识点时，交了答案也能借用这里生成的定位和清单。

**做过的题**：在 Math Academy 的学习主页（/learn）点开一个已经做完的任务，会列出它的每道题、你的答案、对错和解答。一题跟着屏幕上正在看的那一道走（往下滚就跟过去），这些题都已经交过答案，所以翻译、前置知识、定位、「学这个有什么用」、问一问和更简单的解释全部可用。能认出这个任务属于哪个知识点时，借用当初那节课的定位和清单。学习主页本身、Topics 这类目录页，一题只提示怎么进到能跟的页面。

**复习**：复习页自己没有讲解。如果这个知识点当初的那节课是开着一题学的，复习题就借用那节课：前置知识把那节课教的内容当作"这节课在教"排除掉；交了答案之后，定位和「学这个有什么用」直接用那节课的同一份。没有那节课的记录时，交了答案之后按这道题生成。交答案之前，复习题不显示定位和「学这个有什么用」：说出这道题属于哪个模块，本身就是在提示用哪个方法。复习题的前置知识也更严：这道题直接考的那个知识点本身（定义、公式、求法）不列，只列更基础的一层。
**复习**：Math Academy 的复习页面当作练习题，跟着屏幕上正在看的那一题走（往回翻、往下滚，都会跟过去）：交答案之前只能问前置知识，问一问看不到题目；交了答案之后什么都可以问。测验、诊断、测评这些是在测你自己会不会，一题不参与。

**Math Academy 官方前置**：Math Academy 在知识点讲义页的侧栏、学习主页每个任务下面列着它自己的前置知识点。一题读到时按知识点记下名字和链接（存在浏览器里插件自己的存储中，只有名字和链接），以后这个知识点的课、复习、做过的题，「前置知识」面板最上面都会显示一行「Math Academy 官方前置」：名称翻成中文（一次便宜的调用，每个名称只翻一次），鼠标停上去看英文，点一下在新标签页打开那个知识点的讲义。复习题交答案之前不显示（前置知识点的名字会透露这道题属于哪一块）。它们也交给模型参考：前置知识清单以它们为主干，定位里的「建立在」直接用它们，「学这个有什么用」把它们当作「从哪来」；复习题交答案之前同样不交给模型。上课页面本身不列前置知识点，所以要先在讲义页或学习主页见过它们。

**前置知识**：每一步下面有「前置知识」按钮：模型列出这一步背后更基础的概念、方法和公式（3 到 6 项，公式会渲染出来）。它只是参考，不是 Math Academy 的官方清单。
- 讲解和例题：列的是读懂这一步需要、但更早就该学过的基础知识，不含这一步自己教的东西。
- 练习题：列的是做这道题背后更基础的知识；不写这道题怎么做，不含这节课新教的内容，也不会出现选项的原文。
- 每一项旁边有「进一步展开」：模型把这个知识点讲清楚，给一个它自己想的小例子，再说一个常见的误区。展开时模型**看不到题目**，讲的是通用的知识，不联系这道题，也不延伸到这节课新教的内容。
- 展开之后，觉得还是难，点「更简单的解释」：模型拿着刚才那一版讲法，重新讲给一个相关基础更少的人听（术语先用日常的话说，步骤拆得更小，例子更具体）。最多再简化三次；每次的讲法都留着，可以点「上一种讲法」回去看。这一步模型看到的仍然只有这个知识点、这节课教什么和刚才那一版讲法，**看不到题目**。
- 练习题交答案之前看过、展开过、要过更简单的解释，都会记下来，和语音问前置知识一起算在"交答案前问过前置知识"里。

**定位**：步骤标题下面一行，说这节课在数学里的位置：科目 · 模块 · 学段（例如「代数 · 二次函数 · 初中阶段」）。点「展开」看这节课大概讲什么、这个模块是做什么的、建立在哪些更早的模块上。一节课一份，只看这节课讲解和例题的标题和每一段开头的摘录（标题常常只是 Introduction），不看题目；第一次点「前置知识」或「学这个有什么用」时先生成它，再拿它当上下文生成清单（第一次会多等几秒），也可以直接点标题下面的「这节课在数学里的位置」。复习页没有课的标题，交答案之前没有定位（说出这道题属于哪个模块本身就可能是提示），交了之后按那道题生成。

**学这个有什么用**：「前置知识」旁边的按钮，讲这节课以后通向哪里，分两部分：
- 工程化与现实应用：再学哪几个模块，就能解决哪一类工程问题，对应现实里的哪件事。分三层：身边（日常生活）、大工程（大型工程项目）、黑魔法（听起来不像数学的应用），每层最多两条，找不到真实贴切的例子就不写。
- 高级数学衔接：这节课的知识往上会长成哪些更高级的数学，那一层又能解决什么问题。
- 每一条标着离现在多远（很快会学到、再往后几年、大学或以后），都可以点「具体怎么用上」，看这条路怎么走过去和一个小例子。
- 高级数学衔接的每一条还有「那一层有什么用」：走到那一层数学之后，现实里拿它做什么（1 到 3 个用途，每个说明它和这节课怎么连起来）。只有一层，不再往下套。
- 「具体怎么用上」和「那一层有什么用」点开后，都可以点「更简单的解释」，和别处一样最多再简化三次，可以来回翻。
- 觉得不对，点清单下面的「不太对？重新整理」重新生成一份。
- 一节课一份：在这节课任何一步打开，看到的都是同一份，只在第一次生成。模型只看到这节课讲解和例题的标题和开头摘录、这节课的定位，以及这节课已经列过的前置知识的名称（有就带上，没有不等），看不到题目。复习页没有标题，就按那道题生成。练习题交答案之前没有这个按钮，服务端也拒绝：那时候在做题，这是做完以后看的。

**问一问**：平时收起，点开才出现：随时问，可以问很多轮，不打分，⌘↵ 发送。它记得前面聊过的（最近 12 条）。它看到什么，取决于这一步：
- 讲解和例题：看得到这一步的全文，什么都可以问。
- 练习题，交答案之后：看得到题目、选项、你选的、对错和官方讲解，可以完整地讲，包括这道题怎么做、你哪里想错了、别的选项为什么不对。答错了也不会自己去问模型（Math Academy 自己会给出官方讲解）；想让它针对你选的答案讲，点输入框上面的「讲讲我错在哪」就行。有回复之后，那一排换成一点就问的追问，比如「再讲简单一点」。
- 练习题，交答案之前：**看不到题目**，只看到前置知识清单和这节课在教什么。你可以问基础概念、基础方法，它不知道你在做哪道题，所以即使你把题目贴给它、问它选哪个，它也没法帮你解。

**更简单的解释**：讲解、例题，或者练习题交了答案之后的官方讲解，下面都有「更简单的解释」：模型把 Math Academy 写的内容重新讲给一个相关基础更少的人听（术语先用日常的话说、第一次出现带英文原词，步骤拆得更小，用原来的数字）。官方的字原样留在上面，模型写的另放一块。还嫌难可以再点，最多三种，每种都留着，可以点「上一种讲法」回去，「收起」只是折起来。**练习题交答案之前没有这个按钮，服务端也拒绝**：那是这道题自己的字，交答案之前不能讲。

**语音陪练**：顶栏的「语音」或 ⌘] 开始／结束，一律中文讲解，英文原词用英文说。讲解和例题：它讲这一步的道理和里面的英文说法；练习题交答案之前只补前置知识；交答案之后讲这道题。换到下一步，或者练习题交了答案，这次通话自动结束。语音按钮就在问一问那一栏里，说的话和打的字是同一条对话，按时间排在一起，语音的那几句带一条淡线和「语音」小标题。

**划线提问**：在前置知识、讲解、例题、交答案之后的讲解，或者对话里划一段字，旁边会浮出「解释 / 举例 / 为什么 / 引用」：点前三个直接送进问一问，「引用」只把这段话放进输入框，由你接着写。公式按 TeX 引用，不会变成乱码。**练习题交答案之前，题目和选项这两处不出按钮**（问一问本来也看不到题目），前置知识和对话里照常可以。

## 设置

常用的几项在网页的「设置」里就能改（存在 `data/settings.json`，优先于 `.env`）；其余的写在 `.env` 里，模板和说明见 [.env.example](.env.example)：

| 变量 | 作用 |
|---|---|
| `GEMINI_API_KEY` | 文字部分（默认）和语音陪练 |
| `TEXT_PROVIDER` | 文字部分用 `gemini`（默认）、`deepseek` 还是 `qwen` |
| `DEEPSEEK_API_KEY` | `TEXT_PROVIDER=deepseek` 时需要 |
| `GEMINI_MODEL` / `GEMINI_TRANSLATE_MODEL` | 文字模型；翻译默认用更便宜的 flash-lite |
| `VOICE_PROVIDER` | 语音用 `gemini`（默认）还是 `qwen` |
| `DASHSCOPE_API_KEY` / `DASHSCOPE_REGION` / `DASHSCOPE_WORKSPACE_ID` | `VOICE_PROVIDER=qwen` 时需要；key 按区域分开 |
| `QWEN_REALTIME_MODEL` / `QWEN_VOICE` | Qwen 的实时模型和音色 |
| `YITI_PORT` | 端口，默认 4318（改了要同时改扩展 `manifest.json` 和 `background.js` 里的地址） |

每次模型调用的用量和按官方价格算出的花费记在本地数据库，`/api/usage` 可以查看。用 Gemini 实测一小时大约 $0.1，八成以上是语音。Qwen 语音只记 token 数、不估算金额（它的价格这里没有可靠来源），实际费用看百炼控制台。

## 文件

- `edge/`：浏览器插件版的专用部分：在侧边栏里跑引擎的 `backend.js`、浏览器存储 `store.js`、百炼语音的 WebRTC 连接 `rtc.js`，以及 `build.mjs`（把 `server/` 里能在浏览器跑的模块、`web/` 页面和提示词组装成插件）。
- `extension/`：本机服务版用的小扩展（插件版也用同一份 `extract.js` 读页面）。`extract.js` 在 Math Academy 页面里读当前步骤（公式取 TeX，并用页面自带的 MathJax 转成 MathML），`relay.js` 和 `background.js` 转交给本机。
- `server/`：本机服务，只监听 127.0.0.1。`board.mjs` 跟踪当前步骤和每一步的记录；`teach.mjs` 是翻译，`prereq.mjs` 是前置知识清单和展开，`chat.mjs` 是问一问（练习题交答案前，它看不到题目），`llm.mjs` 选 Gemini、DeepSeek 或千问；`translate.mjs` 保证翻译时公式原样保留；`voice.mjs` 是语音中继（key 只在服务端），`voice-providers.mjs` 把 Gemini Live 和 Qwen-Omni-Realtime 各自的协议翻译成同一组事件。
- `prompts/`：提示词。
- `web/`：页面。公式用浏览器原生 MathML 显示，按白名单重建，不插入原始 HTML；`tex.js` 把模型写的 LaTeX 转成 MathML。`retell.mjs`（在 `server/`）是所有「更简单的解释」共用的那一套（一次次讲得更简单、每一版都留着、可以翻回去），`web/retell.js` 是它下面那一行按钮；`simpler.mjs` 是讲解和例题的更简单的解释，`later.mjs`（也在 `server/`）是学这个有什么用，`place.mjs` 是定位，`size.js` 是字号，`dock.js` 是问一问栏（收起、展开、拖动大小）（拖动大小、收起），`thread.js` 把打字和语音排成一条对话，`ask.js`／`pick.js` 是划线提问（`ask.js` 管哪里可以问、问什么，`pick.js` 管浮出的按钮）。
- `data/`：本地数据库和 token，不提交。
